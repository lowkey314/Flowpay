# Kinetic Capital Pay LLC

A polished digital banking and payout dashboard demo.

## Included

- Total balance and monthly activity overview
- Checking, savings, and travel accounts
- Quick actions for sending, adding funds, bills, and cards
- Transaction history
- Spending insights
- Upcoming bills
- Responsive desktop and mobile layout

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:8080`.

## Demo notice

This project is a frontend prototype. It is not a regulated bank, does not hold customer funds, and should not be presented as offering real banking services without the required licensing, partnerships, disclosures, security, and compliance controls.
